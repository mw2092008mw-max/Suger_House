# SUGAR HOUSE — سكر هاوس للحلويات

صفحة متجر عربية باتجاه RTL مبنية بـ HTML وCSS وJavaScript فقط، وجاهزة للعرض أو الاستضافة الثابتة على GitHub Pages.

## التشغيل والتعديل

- افتح `index.html` مباشرة، أو ارفع محتويات هذا المجلد إلى GitHub Pages.
- حدّث بيانات المحل والتصنيفات والمنتجات والأسعار والعروض في `data.js`.
- ألوان الهوية ومقاسات العرض والاستجابة للشاشات موجودة في `styles.css`.
- سلوك البحث والسلة وواتساب موجود في `app.js`.
- الصور وخطوط Google Fonts خارجية. عند فشل تحميل صورة، تعرض الصفحة خلفية زخرفية بديلة؛ والخطوط لها بدائل نظام مناسبة.

## بيانات العرض وحدود التشغيل

الأسماء والأسعار والعروض والتقييمات ورقم الهاتف والعنوان وبيانات التواصل الواردة في الصفحة تجريبية لأغراض العرض. يلزم استبدالها بالبيانات الفعلية والتحقق منها قبل الاستخدام التجاري. صور Unsplash صور توضيحية وليست صورًا لمنتجات المتجر الفعلية.

السلة تعمل في المتصفح وتحفظ محتوياتها محليًا في `localStorage`. زر إتمام الطلب ينشئ رسالة واتساب تتضمن المنتجات والكميات والإجمالي؛ لا يوجد دفع إلكتروني أو مخزون أو حفظ طلبات على خادم. يجب تأكيد الطلب والتوافر ووسيلة الدفع مباشرة مع المتجر عبر واتساب.

## ملفات المشروع

- `index.html` — الهيكل الدلالي والبيانات الوصفية.
- `styles.css` — الهوية البصرية والتصميم المتجاوب.
- `data.js` — بيانات النشاط والقائمة والعروض والتقييمات في مكان واحد.
- `app.js` — البحث والتصفية والسلة ورسائل واتساب.
